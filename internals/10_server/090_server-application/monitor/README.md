# Monitor

**Version**: 0.1 · **Last Updated**: 2026-08-24 · **Status**: 🔴 DA REVISIONARE

One page that answers "what is my server doing right now?" for every mounted app
at once. The `_server/monitor` section renders it through the `app_snapshot` /
`app_panel` / `panel_source` contract every `BaseApplication` can implement.
