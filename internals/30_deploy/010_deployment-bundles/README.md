# Dynamic groups and application bundles

**Version**: 0.1 · **Last Updated**: 2026-08-24 · **Status**: 🔴 DA REVISIONARE

🔴 Unratified proposal. Groups as dynamic runtime objects — added, refreshed and
removed while the server lives — each pinned to an immutable application bundle
built by the application's own CI and distributed through S3, with named builds,
mutable channels and explicit cohorts. A customer tries a change with named users
while production runs untouched, and the build accepted is promoted as is.
