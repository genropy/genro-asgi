# CLI

**Version**: 0.1 · **Last Updated**: 2026-08-24 · **Status**: 🔴 DA REVISIONARE

An admin drives installations from the shell with the `genroasgi` command:
`serve` by instance name, `apps`, `stop`, `remove`, and the instance registry
behind them. The CLI reads the same recipe the server reads and adds no words of
its own.
