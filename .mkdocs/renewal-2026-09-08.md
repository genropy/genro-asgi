## Reader and build changes

The reproduced baseline had 74 strict-build warnings: 73 relative source links
and one root `pyproject.toml` link. Clicking the middleware source link in the
browser produced a 404. The reader now generates numbered views of linked
`src/**/*.py`, `tests/**/*.py` and root `pyproject.toml` from this checkout,
including uncommitted edits. Original Markdown is untouched by rendering.
Traversal, symlink escape, unsupported queries and invalid line ranges are
rejected. Generated views are excluded from navigation/search. Mermaid redraws
for palette changes and contains wide diagrams inside their scroll panel.

Sphinx resolves imports relative to `conf.py`, uses real dependencies and fails
on warnings. Four docstrings were reformatted to remove docutils ambiguity;
the executable Python AST is unchanged. A focused documentation workflow runs
for relevant pull requests to `develop`. [Development commands](README.md)
cover installation, builds, rendered-link checks, reader start/stop and browser QA.
