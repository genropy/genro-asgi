# Subcommanders

**Version**: 0.1 · **Last Updated**: 2026-08-24 · **Status**: 🔴 DA REVISIONARE

🔴 Unratified proposal. Delegated authorities — root → subcommander → group →
worker — each own their domain: the root holds the user-to-branch directory and
the budgets, the subcommander holds its groups and their placement. One policy
owner per resource, budgets granted downward, transfer through the shared freezer
with epochs, and lease and fencing so no stale authority ever comes back.
